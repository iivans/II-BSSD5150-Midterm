# II-BSSD5150-Midterm

Welcome to the project repository for II-BSSD5150-Midterm, a game created using the Unity platform. Because the files provided so far only cover a partial snapshot of the project, this overview focuses on the main elements currently visible.

At its core, the project brings together the essentials needed to run a playable experience, including tracking the overall game state, handling player controls, and managing interactive objects. Players navigate through environments featuring moving obstacles and enemies, all supported by scrolling background visuals. Additionally, the repository includes reference documentation and assets from external creators like BayatGames and Dragon Warrior.
